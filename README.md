# Waso Strategy – Frontend

A responsive, single-page landing website for **Waso Strategy**, a business consulting agency. The project covers the header, navigation, hero section, services, portfolio projects, contact form, and footer.

## Features

- Responsive header and navigation menu
- Hero section with call-to-action buttons
- Services section with a feature list
- Projects grid with hover effects
- Contact section with a form and embedded Google Map
- Font Awesome icons and Google Fonts (DM Sans)

## Tech Stack

- HTML5
- CSS3
- Font Awesome 6.5.1 (CDN)
- Google Fonts (CDN)

## Project Structure

```
waso-strategy-frontend/

```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/waso-strategy-frontend.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser. No build step or installation is required.

## Usage

Edit `index.html` to change the content, and update `css/style.css` to change the styling.
